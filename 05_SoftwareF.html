Téléchargement de DtmVic (version 6.2)

Logiciel DtmVic (Data and Text Mining: Visualisation, Inférence, Classification)
Statistique Exploratoire Multidimensionnelle pour données complexes comprenant des données numériques et textuelles.


Les applications concernent principalement le traitement des enquêtes comportant des questions ouvertes, les explorations de textes (avec ou sans meta-data).

- Aspects spécifiques :

Complémentarité des techniques de visualisation (Analyse en composantes principales, Analyse des correspondances simples et multiples) et de la classification automatique (méthode mixte combinant classification hiérarchique [critère de Ward] et centres mobiles [k-means]; cartes auto-organisées de Kohonen; Arbres additifs).

Validation des techniques de visualisation : Ré-échantillonnage (bootstrap, bootstrap partiel, bootstrap total, bootstrap sur variables). Trois options pour le bootstrap total: Type 1: simple correction de signe pour les axes. Type 2: comme type 1, + correction des interversions d'axes. Type 3 rotations procrustéennes pour rapprocher les réplications de l'échantillon initial.

Analyse de contiguïté et méthodes voisines. Cartes de Kohonen (SOM).

La présente version de ce logiciel académique permet de faire tourner une batterie d'exemples typiques.
[treize exemples d'application commentés et trois exemples d'importation de données sont disponibles].

Des procédures d'importation facilitent l'utilisation des données externes.
Le menu "Create a command file" permet de générer facilement de nouvelles commandes d'analyse.

Limitations de cette version: 30.000 répondants (individus, lignes), 1200 variables (numeriques ou nominales), 100.000 caractères pour les réponses d'un individu à des questions ouvertes. Pas de limites théoriques de tailles pour les textes, dans le cas d'analyses de textes non insérés dans des fichiers d'enquêtes

ATTENTION: Pour tous les utilisateurs, si vous n'êtes pas administrateur de votre ordinateur, et si l'accès à certains dossiers vous est interdit, installez le logiciel dans un dossier auquel vous avez librement accès et dans lequel l'écriture est permise.
