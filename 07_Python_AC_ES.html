El programa de análisis de correspondencias (AC) que se presenta aquí está diseñado con el espíritu del análisis exploratorio de datos. Insistimos entonces en el papel fundamental, para las interpretaciones, de filas (variables) adicionales [o ilustrativas] y columnas (individuos) adicionales .

Este programa independiente no se refiere a los programas de AC existentes. Al igual que en el caso del análisis de componentes principales, este programa solo utiliza las tres bibliotecas clásicas de Python NUMPY (para el cálculo de vectores y matrices), PANDAS (para la gestión de tablas de datos) y MATPLOTLIB (para los gráficos).

  AC: Un ejemplo y el código comentado

El pequeño archivo de ejemplos es una tabla de contingencia (o frecuencia) ya utilizada en el capítulo 3 del libro "Statistique Textuelle" [en francés] (Ludovic Lebart y André Salem, Dunod, 1994, para la primera edición). Puede acceder directamente al capítulo 3 de este libro haciendo clic en: Statistique Textuelle, chapitre 3 . (El libro completo se puede descargar haciendo clic sobre: Statistique Textuelle ). El mismo ejemplo introductorio se comenta tambien en detalle [en ingles] en el Capítulo 3 del libro "Exploring Textual Data" (Lebart, Salem y Berry, Kluwer Academic Publishers, 1998). Se puede descargar un extracto adaptado del capítulo 3 que contiene el ejemplo de: [Exploring Textual Data, extracto del capítulo 3] . Todo el libro todavía no es de dominio público.
