(Requisiti di sistema: Microsoft Windows XP ® Windows Vista, Windows 7, Windows 8.1, Windows 10 ®)

Software DtmVic

("Data and Text Mining: Visualization, Inference, Classification")

Statistica esplorativa dei complessi insiemi di dati che comprende sia dati numerici e testuali. [Applicazioni per il trattamento statistico delle risposte a domande aperte in indagini socio-economici a campione.].

- Particolare attenzione su:

Complementare uso di tecniche di visualizzazione (Analisi delle componenti principali, Analisi delle Corrispondenze) e le tecniche di clustering [ibrido metodo utilizzando sia il clustering gerarchico e il metodo k-means;] Self Organizing Maps (SOM), Additive Trees.

Valutazioni tecniche di visualizzazione: Tecniche di ricampionamento (bootstrap, bootstrap parziale, bootstrap totale, bootstrap per variabili). Tre tipi di bootstrap totale sono previste: Bootstrap totale di tipo 1: semplice cambiamento di segno degli assi per la replicate analisi, quando necessario. Bootstrap totale di tipo 2: come di tipo 1, più: eventuali correzioni di cambio di assi. Bootstrap totale tipo 3: le correzioni della replicato principale sottospazi utilizzando procrustean analisi.

Contiguità e dei relativi metodi di analisi. Mappe Kohonen (SOM).

L'attuale versione di questo libero software contiene una serie di esempi tipici di dati trasformazione e di trattamento dei dati testuali.
[dodici esempi di applicazione e cinque esempi di importazione dei dati sono disponibile] .

L'utente può eseguire il software sul proprio set di dati tramite cambiando pochi parametri e che soddisfano i formati di input mostrato negli esempi (dati, testi e dizionario).
Diverse procedure di importazione può rendere più facile l'ingresso dei dati.
La voce di menu: "Crea un file di comandi" permette all'utente di generare facilmente un file contenente i parametri di controllo.
Dal marzo 2007, i nuovi accessori della serie di bootstrap possibilità. Dal settembre 2007, la valorizzazione del l'importazione da Excel (r), l'esportazione dei file dtm in Excel o R.

Limitazioni su questa versione: 30 000 intervistati (persone fisiche, le righe), 1.200 variabili (numerico o categoriale), 100 000 caratteri per la risposta di un individuo ad una serie di domande aperte.

ATTENZIONE: Per gli utenti di Windows XP che non sono amministratore del proprio computer: si prega di installare in un DTM directory in cui si dispone di un accesso.
