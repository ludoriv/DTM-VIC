Software DtmVic

("Data and Text Mining": Visualização, Inferência, Classificação)

Investigação Estatística Multidimensional para dados complexos, tantos numéricos como textuais. [As aplicações envolvem principalmente o processamento das enquetes com perguntas abertas.].

- Aspectos específicos:

Complementariedade das técnicas de visualização (análise dos principais componentes, análise de correspondências simples e múltiplas) e da classificação automática (método misto, combinando classificação hierárquica – critério de Ward – e centros móveis – médias-k; mapas auto-organizados de Kohonen; Additive Trees).

Validação de técnicas de visualização: re-amostragem (bootstrap, bootstrap parcial, bootstrap total, bootstrap sobre variáveis). Três opções para o bootstrap total:
Tipo 1: simples correção de sinal para os eixos;
Tipo 2: igual ao Tipo 1 + correção de intervenções de eixos;
Tipo 3: rotações procrustéennes para aproximar as cópias da amostra original.

Análise de contiguidade e métodos vizinhos. Mapas de Kohonen (SOM)

A versão atual deste programa acadêmico permite executar uma bateria de exemplos típicos
[estão disponíveis 12 exemplos de aplicações comentadas e cinco exemplos de importação de dados].

O usuário pode rodar o programa com seus próprios dados, mudando um número bem limitado de parâmetros e respeitando os formatos de entrada dos dados numéricos, textuais e do dicionário.
Os procedimentos de importação facilitam a utilização de dados externos.
O menu «Create a command file» permite gerar facilmente novos comandos de análise.

Limitações desta versão: 30 000 participantes (indivíduos, linhas), 1.000 variáveis (numéricas ou nominais), 100 000 caracteres para as respostas de um indivíduo para as questões abertas.

ATENÇÃO: Para os usuários de Windows, se você não é administrador de seu computador e se você não tem acesso a certos arquivos ou diretórios, instalar o programa dentro de um diretório ao qual você tenha livre acesso.
